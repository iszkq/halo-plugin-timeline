# 时间轴

## 简介

为 Halo2 提供时间轴组件、横向/竖向布局，可在编辑器中灵活插入，自动适配深色主题。


## 开发环境

- Java 21+
- Node.js 18+
- pnpm

## 开发

```bash
# 启用插件
./gradlew haloServer
# 开发前端
cd ui
pnpm install
pnpm dev
```

## 构建

```bash
./gradlew build
```

构建完成后，可以在 `build/libs` 目录找到插件 jar 文件。
